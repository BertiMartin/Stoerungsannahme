📥 Ticket erfassen / importieren
So geht's:
1. Öffne das Ticket in osTicket im Browser
2. Klicke irgendwo auf die Seite, dann Strg+A (alles markieren)
3. Strg+C (kopieren)
4. Hier ins Textfeld klicken und Strg+V (einfügen)
5. „Daten erkennen" klicken – das Dashboard liest Gerätenummer, Fehler, Region & Priorität automatisch aus.
So geht's in osTicket:
Offene Tickets → oben rechts das Export-Icon (↗) → Export as CSV oder Excel → Datei speichern → hier hochladen.
